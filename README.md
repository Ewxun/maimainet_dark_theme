# Maimai Net Dark Theme

This is a Chrome extension that applies a dark theme to Maimai Net. The lack of a dark theme on Maimai Net kinda hurts my eyes, so I made this extension to fix that. <br>
This is mainly made for my own use, but feel free to use it if you want. You can fork the project to customize it to your liking. <br>
I will try to keep it updated with any changes to Maimai Net, but I can't guarantee that it will always work.

# Installation
1. Download the the repo as a zip file and extract it to a folder
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode" in the top right corner
4. Click "Load unpacked" and select the folder where you extracted the zip file
5. The extension should now be installed and have dark mode enabled by default. You can toggle it on and off by clicking the extension icon.
